# What this is all about?
A lightweight concept app showing how Apple HealthKit data can be turned into clear, meaningful charts.

It pulls live health metrics from the device and displays them in a way that helps users track progress and spot trends. 

Built entirely with native Apple tools. Includes AI Module: AI Coach analyses step count and health data to motivate people to get fit.

# Technologies Used
- iOS26
- Apple Intelligence: Foundation Models - Language Model
- SwiftUI
- HelthKit
- Swift Charts
- Swift Algorithms
